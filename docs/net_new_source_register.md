## 3. THE HIDDEN-SOURCE PATTERN

Eleven classes of source were found **only** by enumeration. Each has a repeatable rule.

### 3.1 Per-topic and per-year hosted FeatureServers with no page linking them
**Where found:** Buncombe `Unpaid Property Bills from 2026`, `…2025`, `…2024`, 2009-2023; Pickens `dqnt_2024`, `dqnt_2023`, `dqnt_2022`, `del_2021`, `delinquent_2020`, `Posting3`, `DelParces_October2025NewsAd`, `FLC_2022`; Oconee `DT2025`, `DT2024`, `DT2023`, `DelqTaxSale_2015`; Burke `Disposable_BC_Owned_Parcels_FS`, `Tax_Sales_FS`, `Burke_Parcel_History_v3`.

**Rule:** GET `https://services{N}.arcgis.com/{ORGID}/arcgis/rest/services?f=json` and **read the service names as a list**, not the county website. Counties that publish a distress dataset annually create a **new service per cycle** with a year in the name. Grep the service list for `dqnt|delinq|unpaid|tax|DT20|FLC|posting|damage|forecl|surplus|owned|vacant|condemn|history|sales`. Then poll that root monthly: when the 2026 cycle opens, the service appears there before any page links it. Buncombe alone had 591 services with 245 keyword matches.

### 3.2 Non-zero layer ids
**Where found:** Spartanburg `Property_Damage_Assessments/FeatureServer/**25**`, `Palmetto_Property_Damage/**2**`, `Private_Property_Cleanup_Locations/**13**`, `City_Owned_and_Vacant_Properties/**1**` and `/**4**`, `Parcel_Archive/**6**`; Burke `/**194**`, `/**158**`, `/**119**`, `/**106**`, `/**112**`, `/**142**`; Polk `LU_Parcels/**153**`, `Site_Addresses/**8**`; Pickens `Pickens_Open_data/**6**`, `Energov_AGOL/**7**`; Laurens `Baselayers/FeatureServer/**84**`; Lincoln `Riverbend/**72**`, `OpenGov/MapServer/**58**`; Transylvania `Parcels_Downloadable` at layer **2**.

**Rule:** Never assume `/0`. Always GET the **service** JSON first (`…/FeatureServer?f=json`) and enumerate `layers[]` and `tables[]` by name. A scraper hard-coded to `/0` against Spartanburg's damage service returns nothing while layer 25 holds 1,531 rows. Corollary: within one service, different layers can be entirely different datasets (Spartanburg's `City_Owned_and_Vacant_Properties` has vacant parcels at 0, annexation agreements with sale tracking at 1, and city-owned parcels at 4).

### 3.3 ArcGIS `definitionExpression` curated ID lists inside webmap `/data?f=json`
**Where found:** Henderson (the 15-REID delinquent foreclosure list, webmap `7c89c21f8cf6401bbb71560ab9c09ab8`); Oconee (`Redeem_Assign='ASSIGNED'`, `Status='NONE'`, and the decommissioned Permits service's `PermitStatus='Issued'`/`'Finaled'`).

**Rule:** For every Web Map, Web Experience, Dashboard, Instant App, StoryMap and Hub app in the org, fetch `https://www.arcgis.com/sharing/rest/content/items/{ITEMID}/data?f=json` (or the Enterprise Portal equivalent) and regex-extract `operationalLayers[].url` plus every `definitionExpression` and `where`. A curated distress list often exists **only** as a filter clause inside an app config; the underlying layer is the full parcel fabric.

**Important negative:** this pattern did **not** repeat in Buncombe, Gaston, Cleveland, Rutherford, Lincoln, McDowell, Polk, Transylvania, Mitchell, Anderson, Pickens or Union. In those counties the curation lives in **layer and service names** instead ("Vacant Parcels ≥25 Acres", "County Owned Property", "Disposable BC Owned Parcels"). So run both passes: expression extraction **and** name-list grep. Also note Oconee's decommissioned Permits service, whose definitionExpressions survive in live web maps after the service itself 404s, which is how you recover a schema for a source that may come back.

### 3.4 AGOL and Portal org enumeration, with the `q=*` trap
**Where found:** Buncombe org `VLA0ImJ33zhtGEaP` (306 items under `GISAdminBC` plus 3 more accounts); Henderson `ZfV5vUaX5QvLLBi9`, where the entire code-enforcement stack was owned by a **fourth** account (`paulinajones@`, 9 items) nobody had enumerated; Burke `axQ4OCSpcxALIQsV` (550 items); Pickens `59960rq18IxUcAVI` (330 items); Oconee `UOvRn2Rvzysthh3i` (219 items); Lincoln `TaX0xkzgvxdv4n56` (489 items across 3 owners); Transylvania Enterprise Portal (78 items).

**Rule:** Anonymous `search?q=*` frequently returns **0** and anonymous `portals/self` frequently returns `id: null`. That is a trap, not an absence. Enumerate by `q=orgid:{ORGID}`, by `q=owner:{USERNAME}` for every username you can find, and by `q=type:"Feature Service"` / `type:"Web Map"`. Harvest usernames from item `owner` fields on any single item you can reach, then loop. On self-hosted Enterprise Portals (`…/portal/sharing/rest/search`) the same rule applies: `q=*` returns 0, `q=owner:portaladmin` returns 78.

### 3.5 Second and third ArcGIS hosts named only inside JavaScript config
**Where found:** Lincoln `gis.lincolncountync.gov/**server**/rest/services` (35 services across 11 folders including `Tax` and `OpenGov`), discovered only from `taxparcelviewer/assets/Lincoln/LincolnLayerConfig.js`; McDowell `www.webgis.net/arcgis/rest/services/NC/McDowell/MapServer`, discovered only from `siteSettings.js` (`aaCfg.restURL`); Gaston's city server discovered from `gastonianc.gov/code-enforc.html` leaking `experience.arcgis.com/experience/124b41fac8aa42959265ff9f1eaea3f3`; Union's entire `tgis` API recovered from `tgisServer2.js`; Laurens' Portal recovered from `/parcel/config.json`.

**Rule:** Hostname guessing (`gis.`, `maps.`, `arcgis.`, `gisweb.`, `mapping.`) is necessary but not sufficient and produced NXDOMAIN in half the counties. Always fetch the **map viewer application** and pull its JS bundles and config files: `config.json`, `siteSettings.js`, `*LayerConfig.js`, `assets/{County}/*.js`, `cdn/{n}/config.json` for Experience Builder, and the WAB `config.json`. Grep those for `http`, `rest/services`, `restURL`, `portalUrl`, `.ashx`, `.aspx?cmd=`. Lincoln's second host and McDowell's real parcel layer were both unreachable by any naming pattern.

### 3.6 Arcade `expressionInfos` in popup definitions
**Where found:** Transylvania, where the Tax Web Map's popup Arcade expressions yielded four undocumented per-parcel URL templates: the appraisal-card PDF (`GISReports/propertyreports/Parcel_{PIN}-{CARD}.pdf`), the Farragut tax-bill deep link, the parcel-search link, and the deed URL.

**Rule:** After fetching a webmap's `/data?f=json`, do not stop at `operationalLayers[].url`. Parse `popupInfo.expressionInfos[].expression` and `popupInfo.description` for string concatenation building URLs. Counties frequently construct per-parcel document URLs client-side, so the URL pattern exists nowhere on the server and nowhere in the HTML.

### 3.7 WordPress REST APIs (media, pages, categories)
**Where found:** Cherokee SC `wp-json/wp/v2/media` (2,411 objects; `?search=tax sale` surfaced the 529-parcel 2024 ledger that **no page anchors**); Laurens County Advertiser `wp-json/wp/v2/posts?categories=7486` (Notice To Creditors) and `?categories=17` (2,343 obituaries); Tryon Daily Bulletin `?categories=35` (5,675 obituaries).

**Rule:** For any WordPress county or newspaper site, hit `/wp-json/wp/v2/media?per_page=100&_fields=date,title,source_url` and `?search=<term>`, plus `/wp-json/wp/v2/pages`, `/wp-json/wp/v2/posts`, and `/wp-json/wp/v2/categories?slug=<slug>` to discover category ids. Read the `x-wp-total` header for the true object count. **Uploaded-but-unlinked documents are the norm, not the exception**: a PDF-anchor scraper structurally cannot see them. Caveat: some sites (Gaffney Ledger) expose taxonomy counts but gate `posts`, returning `[]` for every query, so verify content is actually served before scoring the source.

### 3.8 Trumba and other calendar feeds, and their sibling calendars
**Where found:** Buncombe. The engine polls `trumba.com/calendars/tax-foreclosures-**all**.{ics,json}`; the raw HTML of `taxforeclosures.buncombenc.gov` (reached only through a JS-less redirect from `/622`) revealed `//www.trumba.com/scripts/spuds.js` + `eventactions.com/eventactions/tax-foreclosures-**details**`, i.e. a **distinct calendar** at `trumba.com/calendars/tax-foreclosures-details.{rss,ics,json}`.

**Rule:** When a county uses a calendar vendor (Trumba, CivicPlus, Granicus), enumerate the **calendar name space**, not just the one feed you found. Fetch the embedding page raw and grep for `spuds.js`, `eventactions`, `/calendars/`, `webName`, `calendar=`. Then try each discovered calendar name against `.rss`, `.ics` and `.json`. Sibling calendars carry different event sets (all vs details vs a specific department).

### 3.9 Vendor tenancy probing, positive and negative, including wildcards
**Where found (positive):** Rutherford + McDowell Sturgis/Catalis open APIs on `d1ebsyxxbc7tep.cloudfront.net/data/{GUID}/…`; Henderson + Burke + Rutherford NCPTS `IsValidTenant → true`; Union Beacon `AppID=861&LayerID=16112`; Laurens Beacon `AppID=1228&LayerID=39077`; Laurens Zuercher `laurens-911-sc`; Cherokee + Pickens Zuercher; Oconee + Cherokee + Union + Laurens qPayBill; Mitchell Aumentum `nc-mitchell.publicaccessnow.com`; Polk + Rutherford Cott; Gaston + Cleveland + Lincoln + Burke Courthouse Computer Systems.

**Where found (wildcard traps):** `*.policetocitizen.com` renders 200 for **any** subdomain and its `api/Inmates/<listId>` ids are **platform-global**, so `unionsc.policetocitizen.com/api/Inmates/23` and `laurenscountysc.policetocitizen.com/api/Inmates/23` both return **Buncombe** data. `smartgovcommunity.com` 404s identically for a bogus tenant. `invoicecloud.com` returns 200 for a deliberately bogus slug, so its 200s are meaningless. `clevelandcountync.policetocitizen.com` renders but its API replies "Agency with name clevelandcountync does not exist".

**Rule:** Probe tenancy with an **API that names the tenant back to you**, never with an HTTP status code. Good probes: `POST lrcpwa.ncptscloud.com/api/IsValidTenant` with `X-Tenant: {County}` (returns literal `true`/`false`); `policetocitizen.com/api/Agency/InitialSettings` (returns the agency name or an error naming the missing agency); checking the `BookingAgency` field on returned rows. Always run a **known-positive control** (Henderson returns `true` on NCPTS) and a **known-negative control** (a nonsense tenant name) in the same pass. Vendor URL shape also varies: Cott is path-based (`cotthosting.com/ncpolkexternal`) in Polk and Rutherford but a separate product (`recordroom.cottsystems.com/unionsc`) in Union, and the subdomain guess `polknc.cotthosting.com` is NXDOMAIN.

### 3.10 Orphan documents behind 403 directory indexes, and CMS document-id drift
**Where found:** Buncombe `media.buncombenc.gov/common/tax/foreclosure-listings/` (index 403, `fcl.pdf` inside it 200); Lincoln `arcgisserver.lincolncountync.gov/ftp/` (index 403, all six zips 200); Cleveland `Document Center/Building Inspections/` (index 403, CSVs 200); Cherokee SC WP uploads (no index at all, files reachable only via the REST media search); Spartanburg FLC `DocumentCenter/View/104130` still 200 but the live page now links `View/102066` and `View/104129`.

**Rule:** A 403 on a directory index does **not** mean the files are protected. Test a known filename inside it. Recover filenames from three places: the raw HTML of the linking page (not the rendered page), the CMS REST API (WP media, DCAT catalogs), and Google `site:` results for orphaned paths. Separately, **CivicPlus/CivicEngage `DocumentCenter/View/{id}` ids rotate**, so any hardcoded id needs a periodic re-resolve against the linking page; the Spartanburg FLC scraper's own docstring warned about this and the drift has now happened.

### 3.11 Human sitemaps, DCAT catalogs, and published spreadsheets when XML sitemaps 404
**Where found:** Cleveland `/main/sitemap.php` (191KB HTML sitemap; `/sitemap.xml` and 3 variants all 404); Polk `sitemap.php` (150 links; XML 404, robots 302s to a 404); Pickens `www.co.pickens.sc.us/sitemap.php` (252KB, 427 hrefs); Rutherford (no robots.txt at all and a Revize CMS that **soft-404s every bad path with HTTP 200 + the homepage**, making sitemap probing actively misleading); Buncombe `data.buncombenc.gov/api/feed/dcat-us/1.1.json` (285 datasets); Polk `polk-county-open-data-polknc.hub.arcgis.com/api/feed/dcat-us/1.1.json` (16); Oconee `data-oconeesc.opendata.arcgis.com/api/feed/dcat-us/1.1.json`; Oconee's official tax-sale list as a **published Google Sheet CSV** (`docs.google.com/spreadsheets/d/e/2PACX-1vS_1zk5YJ…/pub?gid=0&single=true&output=csv`); Laurens' delinquent list as **newspaper e-edition PDFs** behind `1543.newstogo.us/editionviewer/…&View=PDFList` with a persistent `Publication=` archive id.

**Rule:** When `sitemap.xml` and `sitemap_index.xml` 404, try in order: `sitemap.php`, `/main/sitemap.php`, `site_map.php`, then the CMS search view (`/search/all?keys=<kw>` on Drupal 10, as in Transylvania). For any ArcGIS Hub site, always fetch `/api/feed/dcat-us/1.1.json`, which is the canonical machine-readable index. And when a county page says "the list will be posted here", inspect the raw HTML for an **embedded document viewer**: published Google Sheets, iadsnetwork/newstogo e-editions, Trumba spuds, and hidden iframes to `cms.revize.com/revize/apps/{county}/…`. Critically, **do not trust a 200 from a Revize or CivicPlus site as evidence a path exists**; verify by content, because soft-404s return the homepage with a 200.
