**Top 5 net-new**

1. **`Voluntary_Ag_District/MapServer/0` — the 116-field CAMA roll for all 29,541 parcels.** A service whose name promises 53 ag-district polygons is actually the entire Farragut assessment roll. It hands over, free and in one query, the exact fields this footprint has been missing: **833 parcels carrying deferred/present-use value** (a rollback-tax bill triggers the instant they sell), **1,649 with a tax-exempt code and 656 with an elderly/veteran/disabled exemption**, **4,883 with a named mortgage holder**, and **6,306 whose assessed value fell year over year**. Nothing else found in this county comes close, and it is a single GET.

2. **The delinquent-tax stack, 2017–2025 — 1,831 arrears bills, now actually retrievable.** Round 1 left this UNVERIFIED after six failed payload variants. The unlock is the trailing slash on `GetSearchTablePartial/` plus the two-step partial-then-`GetSearchTableData` call that replays the session-stored model. Every row carries owner name, 13-digit PIN, and total due with interest, and the `Online Payment Prohibited` cell marks bills already in attorney hands. Because it is queryable per tax year, this is the first multi-year arrears stack in the footprint that supports repeat-delinquency scoring.

3. **`Helene_SD_Structures/FeatureServer/306` — 44 FEMA substantial-damage determinations.** All 44 are residential, all 44 are `Percent_Damaged >= 50`, all 44 read `Damage_Message = "Substantially Damaged"`, and all 44 carry a PIN plus owner name and mailing address. An NFIP substantial-damage finding legally compels elevate-to-code or demolish. It sat behind **layer id 306** on a host (`services7`) that round 1 never resolved — `/FeatureServer/0` returns `Invalid URL`, which is precisely how a prior pass loses it.

4. **The Farragut sales corpus — 134,272 recorded sales, including 814 priced $1–$1,000.** PIN, deed book and page, deed date, price, price per heated square foot, and a Qualified/UnQualified flag going back to 2000. Deed book+page joins straight into the Logan ROD for grantor/grantee, so this is a genuine free comp spine plus a ready-made family-transfer and heir-distribution detector.

5. **The contact tier: 274 storm-debris rows with a phone on every single one, 69 unmet-needs rows with name + phone + street address on every one, and 113 wildfire-cleanout rows with 60 phones.** Three separate open Survey123 services on an AGOL org (`ProOLvsmwpY1RmFG`) that appears nowhere in the engine source. The debris rows have no address field but do have WGS84 point geometry, so a spatial join to the parcel layer converts 274 phone numbers into 274 PINs.
