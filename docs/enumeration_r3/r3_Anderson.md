**Privacy exposure — reported, not harvested.** `https://gis.cityofandersonsc.com/arcgis/rest/services/EmergencyServices/ProbationList/FeatureServer/{0,1,2}` ("All Probation", "Sex Offender", "Gang Association", **2,241 rows each**) publishes a schema containing **`SSN`**, alongside `DOB`, `DL_`, Last/First/Middle, home `Street1`/`Street2`/`City_1`/`Zip`, Race, Sex, Height, Weight, `MainOffens`, `Program`, `BeginDate`. The Gang Association and probation layers can include juveniles, so `DOB` here is not safely assumed adult. Per the hard rule I requested **layer metadata only and pulled zero rows**, and I ran no query naming those fields. This service should be treated as do-not-touch by the pipeline and, ideally, flagged to the City of Anderson GIS administrator — an anonymous, unauthenticated FeatureServer exposing SSN is almost certainly unintentional. Round 1 listed this service as "NEW (UNVERIFIED depth)"; it should be reclassified **PROHIBITED**.

**Top 5 net-new:**
1. **`WaterUtilities/County_Parcels/FeatureServer/0`** — 114,516 parcels with **113,699 owner mailing addresses**, paginated and geoJSON-capable. One endpoint, no key, and it is the county-wide mail spine plus a de facto bulk assessor-roll download.
2. **ACPASS Register of Deeds (`deedmain.cgi` + `deddetail1.cgi`)** — a free, date-range and instrument-type filtered ROD index with grantor/grantee **roles** (`PR`/`EST`) and an Amount field. Opens the lien / estate-deed / manufactured-home facets that memory records as blocked.
3. **Probate Court public inquiry on `govcloud2.hostedbyspartan.com/AndersonPRO`** — a local, open estates + guardianship/conservatorship index with decedent, heir, PR and incapacitated-individual party types, entirely bypassing the state WAF.
4. **The 5-year rollback / ag-property book stack (2021–2025)** — 209 fixed-width pages per year of TMS, owner, acres, market value, use value and rollback tax per acre. The deferred-value trigger, already parseable.
5. **`arcportal.andersoncountysc.org` Portal item catalog** — proves the county's REST directory listing is filtered and reveals hidden services; the `owningSystemUrl` in `/arcgis/rest/info` is a reusable discovery trick for every other county.

**Biggest remaining gap:** no county-wide **delinquent tax balance** list — per-parcel balances exist only one-at-a-time via `rpcdetail1.cgi`, the 8-year PostingPro stack sits behind a terms click-through I will not accept for you, and the Clerk of Court civil index (lis pendens, judgments, evictions) still routes to the WAF-walled `publicindex.sccourts.org`.
