### Top 5 net-new

1. **Gastonia CityView code-enforcement polygon API** (`devsvcs.gastonianc.gov`) — the only true municipal case *database* in the footprint and by far the best find. Bulk-extractable with no login, 1,000 rows per polygon (grid-subdivide to exceed), history to 2020, and **99.9% of rows carry the Gaston County parcel PIN plus a full street address**, so it joins straight into the existing parcel/owner spine. The `Housing` (minimum housing) and `Public Nuisance` / `Vegetation-Weeds` types are exactly the lien-generating, motivated-seller signals county records miss. 1,781 distinct cases pulled from only two polygons.
2. **Kings Mountain `AtRisk_Parcels` / KM_MasterParcel_MAT** — 7,902 city-maintained parcels with 100% owner-name fill, owner mailing address, year built and assessed values. A municipal-grade owner spine for a Cleveland County city, independent of the county assessor.
3. **Lincoln County eTRAKiT `Violations → Search Code Complaint`** — a real code-complaint database covering Lincolnton and Denver, currently login-walled. Highest-value *blocked* target; worth a records-request or account-registration path since the county says the portal exists "to search existing records."
4. **GCLMPO `BlightProblemReports`** — a live, tri-county (Gaston/Cleveland/Lincoln) blight-reporting service with the right schema (`PROBTYPE`, `STATUS`, `RESOLUTION`) that currently returns 0 rows. Cheap to poll; if the MPO ever populates it, it is a footprint-wide blight feed in one call.
5. **WPCOG regional code enforcement + Mount Holly `Property_Listing`** — WPCOG confirms a *shared* minimum-housing/abandoned-mobile-home/demolition program running across Burke's small towns (a single FOIA target covering Drexel, Valdese and neighbors instead of a dozen), and Mount Holly's 12-row property listing is the only city-published property inventory with owner and parcel in the whole sweep.

**Municipalities that publish something usable:** Gastonia (case database), Kings Mountain (parcel/owner service + searchable minimum-housing document trail), Mount Holly (property listing), plus GCLMPO and WPCOG as regional layers.
**Municipalities that publish nothing usable:** Belmont, Cherryville, Bessemer City, Dallas, Stanley, Shelby, Boiling Springs, Grover, Lincolnton, Morganton, Valdese, Drexel, Forest City, Rutherfordton, Spindale, Lake Lure — every one runs a code-enforcement/minimum-housing program, none posts a case, condemnation, demolition or lien list. Chimney Rock and Rutherford College have no reachable municipal site; Denver is unincorporated.
