### Privacy — exposure found, reported not harvested

`https://services1.arcgis.com/UTZTmZoX2rsa9yFA/arcgis/rest/services/Addresses_with_Services_08_15_25/FeatureServer/14` (service capabilities: `Query`, anonymous) is a **City of Hendersonville water/sewer customer billing file**, not a property record. Aggregate-only counts (I retrieved **no rows**): **32,559** customer records, **31,813** populated `Phone_Number`, **25,085** populated `Email`, plus Name, Customer_Number, billing address, Billing_Cycle, Parcel_Number. Sibling layer `GeoCode_WaterAccounts/FeatureServer/1152` (1,076) carries the same Phone field.

This is customer PII on an unauthenticated endpoint. **Do not ingest either layer.** Recommend notifying the City of Hendersonville GIS/Water & Sewer department. Separately, `VACANT_STRUCTURES_7_24_24` is legitimate code-enforcement public record but its `PHONE__` and `EMAIL` columns should be dropped at ingest — request only the columns listed in the table row.

### Top 5 net-new

1. **`VACANT_STRUCTURES_7_24_24/FeatureServer/0`** — 52 rows, but the highest signal density in the county: vacancy + boarded + condemned + utility-shutoff + **delinquent tax dollar amounts** + owner + absentee mailing address, all in one hand-maintained table. Ingest immediately, minus PHONE__/EMAIL.
2. **`OVT_PublicDashboard_View/FeatureServer/1` with the county's own live WHERE clause** — 163 open cases out of 3,231, refreshed daily, each with parcelOwner + address + PIN, joinable straight to Parcels on PIN. Vehicle Graveyard / Junkyard / MH Graveyard / Minimum Housing are the distress subtypes worth scoring.
3. **`Tax/Data_for_MapMetrics/MapServer/101` (6,638 manufactured homes) and `/2` (33,266 sales)** — an entire owner-and-mailing universe plus a full sales history the engine has never touched, on a server it already calls for one layer. Both sit at non-zero layer ids, which is why the first pass missed them.
4. **The 15 `portal-nc.tylertech.cloud/app/RegisterOfActions/…/anon/portalembed` deep links** on the tax-foreclosure page — pre-authorized per-case dockets that skip Smart Search entirely. The engine already owns the WAF-solving machinery; this just needs a new entry point.
5. **`co-henderson-nc.smartgovcommunity.com`** — a completely unscraped, login-free permit system whose case types include Septic Repair, Septic Tank Abandonment, Well Abandonment and Commercial Demolition, with `/Public/ApplicationInspectionSchedule` already parseable today; pair it with `Failing_Septic_Addresses_in_ETJ` (1,411 addresses).

**Why the first pass returned nothing:** the engine touches `Parcels/FeatureServer/0` and one HTML page. Everything above sits either in a non-root ArcGIS folder (`Tax/`, `Permitting/`), at a non-zero layer id (101, 27, 149, 1142, and OVT where layer 0 does not exist), on a hosted root that the AGOL item search under-reports by 419 services, or inside raw page HTML that no sitemap or link crawl surfaces.
