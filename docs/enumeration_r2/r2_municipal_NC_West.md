### Top 5 net-new
1. **Hendersonville `VACANT_STRUCTURES_7_24_24`** — the single best find in this sweep. 52 hand-curated properties with owner, owner mailing address, and free-text `CONDEMNED` / `DELINQUENT_TAX` / `UTILITIES` ("ACTIVE NO USE FOR YRS") notes. This is a code officer's working motivated-seller list published raw. Zero-cost, one GET, no pagination.
2. **Asheville `AccelaServicesView` re-purposed as a source, filtered on `record_type_category`** — 268 addressed distress cases (Housing Code Referral + Junked Vehicles + Damage-Incident) already carrying `parcel_number`, which skips the name→parcel resolver ceiling entirely. The endpoint is already in the codebase but only ever asked "does this lead have a violation?", never "who has violations?"
3. **Asheville `AshevilleRealProperty` layer 25** — 448 city-owned parcels tagged Strategize / REVIEW / Monitor, i.e. the city's own disposition funnel, with `deedurl` and `acquisition_cost`. Layer **25**, which is why a layer-0 probe would have found nothing.
4. **Fletcher Code Enforcement Tracker** — small (10) but live, growing monthly, and uniquely ships `property_owner_name` + `property_owner_address` in the same row as the violation. Requires the column whitelist described above.
5. **Buncombe County-owned parcels via the recovered `owner = 'BUNCOMBE COUNTY'` definitionExpression** — 105 rows, found only by reading a web map's `/data` rather than the REST directory.

### Who publishes what
- **Publishes usable data:** Asheville (own 36-folder ArcGIS Server, richest municipal source in footprint), Hendersonville (own AGOL org `UTZTmZoX2rsa9yFA`, 515 items), Fletcher (own AGOL org `kb1HFNgBhKksK3Lv`).
- **Own GIS but nothing distress-related:** Black Mountain (org `7ndinM1eAWznyj6s`, 112 items — all water meters, stormwater, zoning), Weaverville (org `lA7fMEY4qaPiZF6g`, 13 items, zoning only), Marion (org `q5DjgI77eZ9vJ4mD`, 144 items — its one relevant layer is token-walled; "Distress Types" is *pavement* distress).
- **Publishes nothing usable:** Woodfin, Montreat, Biltmore Forest, Brevard, Rosman, Flat Rock, Laurel Park, Mills River, Spruce Pine, Bakersville, Old Fort, Tryon, Columbus, Saluda. Structural reason for the Buncombe towns: Buncombe County Permits & Inspections performs inspections for Biltmore Forest, Weaverville and Woodfin under contract, so their code cases land in county systems, not town ones. The small towns' programs are confirmed to exist only through ordinance hosting (Municode for Weaverville/Woodfin, American Legal for Biltmore Forest/Fletcher/Marion/Asheville, EnCodePlus for Brevard) with no case lists posted.
