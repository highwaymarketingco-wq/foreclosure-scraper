### Top 5 net-new
1. **NCDOT ROW Proposed Acquisition (`gis11.services.ncdot.gov/…/RowMsPub/…`)** — 50,579 owner-name annotations in-footprint, joined to deed book/page and parcel number, plus explicit *Remnant* and temporary/permanent easement takings. Uniquely adds a **pre-distress, pre-court motivated-seller signal**: the state is condemning part of your land. Nothing else in the engine sees this. Filter to the 18 counties by envelope (no county field). Caveat: CAD annotation, so owner names split across rows (`BURNETT PICKETT &` / `WIFE LORRI PICKETT`) — needs a `ProjectParcelID` group-and-join.
2. **AddressNC + the NC batch geocoder (`services.gis.nc.gov`)** — 6.2M address points and a **1,000-address-per-call** geocoder. This is the direct fix for the known `geocode @1/sec` bottleneck that hung `run_local.sh` for 8.5h. Infrastructure, not leads, but it unblocks a documented hard wall.
3. **SC RFA statewide geocoder (`gis.state.sc.us/…/RFA_MultiRole_2024`)** — the SC-side counterpart, verified anonymous, returns `PointAddress` at score 100. Partially offsets the SCDOT `SC_Parcels` token wall, which SC currently has no substitute for.
4. **NCEM Hazard Mitigation Parcels Aug-2025** — 4,318 parcels carrying `ownname` **and** `mailadd/mcity/mstate/mzip`. A curated buyout-pipeline list with the mail spine already attached. Only 341 in-footprint, but it is a genuine post-Helene acquisition pipeline and it is invisible to org search.
5. **NCDEQ encumbrance stack (`services2.arcgis.com/kCu40SDxsCGcuUWO`)** — recorded Land Use Restrictions, brownfields, drycleaner and UST sites, pre-regulatory landfills. The engine's `enrichment_environmental.py` only calls EPA `echodata`; NC state-level recorded restrictions are a distinct title-risk and value-suppression layer.
