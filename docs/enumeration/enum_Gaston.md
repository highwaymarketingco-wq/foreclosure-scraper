### Top 3 net-new

1. **`PublicGIS/Parcels/FeatureServer/11` on `gis.gastoncountync.gov`** — 117,565 parcels with owner + mailing + FMV + sale + deed book/page + lat/lon + **`VacantImpro`** + **`PRVYRNAME1/2`**. The engine currently reads the *city* copy (`cogserver.gastonianc.gov`), which has neither the vacancy flag, the prior-year-owner field, nor coordinates. Three ready-made distress cohorts fall straight out of a `returnCountOnly` query: 21,380 vacant, 10,340 absentee-out-of-state, 2,997 vacant **and** absentee, 4,764 ownership changed since last January 1.

2. **DevNet Wedge "Total Unpaid" / "Tax Amounts Due for all unpaid years"** at `gastonnc.devnetwedge.com/parcel/view/{PID}/2026`. This directly closes the taxes-owed capture gap for Gaston, and the PID keyspace needed to drive it is already obtainable in one pass from finding #1. Confirmed live on PID 160271 ($2,980.73 owed vs a $101.25 current-year bill — a 29× delinquency ratio, i.e. the signal is real and multi-year).

3. **GovDeals agency 6393** — Gaston County's surplus real-property storefront, linked from `/709`. `nc_govdeals_real_property.py` only carries agency 22325 (Pender, non-resolving), 29265 (Burke), and the `tcncre` slug; 6393 is absent. Complements the already-scraped surplus PDF, since GovDeals carries the live auction state the PDF does not.

**Compliance note:** two sources are walled and I stopped at classification — `gastoncountyso.policetocitizen.com` (F5 ASM rejection on every path) and the EnerGov CSS search API (HTTP 500 without an authenticated session). The `BCS` and `EnerGov` ArcGIS folders and the `Hosted`/`Cityworks` folders on the city server return `Token Required` and were not probed further.
