### Top 3 net-new

1. **`Disposable_BC_Owned_Parcels_FS/FeatureServer/194`** — the exact Henderson-analog. A curated, county-maintained list of 11 tax-foreclosure/Commissioner's-Deed parcels, each carrying a live `BidLink` to a Burke FormCenter bid form. It is not a page and not in the sitemap; it exists only as an operational layer inside the "Burke County Disposable Property Map" web map (`f9a5b6be8a41462cba6e3954547a3f28`). Critically, this is now the **only working Burke surplus channel** — GovDeals seller 29265 is already flagged non-resolving in the repo, so Burke currently has a silent zero there.

2. **`ProdParcelViewFC/MapServer/0`** — 59,433-row full CAMA extract with owner, complete mailing address, assessed land/building split, sale prices, and deferred-value fields. This is a direct replacement for the dead delinquent-tax lane: 3,171 out-of-state absentee owners and 1,560 parcels carrying deferred (present-use/historic) value whose rollback triggers a three-year tax bill. Open, paginated, no auth.

3. **`Hosted/Burke_Parcel_History_v3/FeatureServer/0-10`** — eleven annual parcel snapshots, 2015 through 2025, ~59k rows each, with owner name, mailing address, sale date, transfer date, and structure count/year. Diffing consecutive years gives ownership-change, new-absentee, and structure-loss detection without any court or ROD dependency. I have not seen this layer type in the other footprint counties.

Runner-up worth noting: `Tax_Sales_FS` (1,669 rows, 2023-2024, with `GRANTOR`/`GRANTEE`/`Sale_Price`/`Qualified`) is a ready-made comp-calibration and cash-buyer-mining set, and `NCEM_Damage_Assessment_BC` has 270 Helene Destroyed/Major structures joined to parcels by `REID`.
