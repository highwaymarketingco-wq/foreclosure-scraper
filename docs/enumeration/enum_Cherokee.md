## Cherokee County, SOUTH CAROLINA — distress source enumeration

### Sweep results (what each returned)

**SWEEP 1 — ArcGIS Server enumeration.** Cherokee County SC operates **no public ArcGIS Server of its own**. Dead DNS on `gis./maps./arcgis./gisweb./mapping.cherokeecountysc.gov`, `cherokeecountygis.org`, `gis.cherokeecounty.sc.gov`, `gis.scacog.org` (the 2010 "Upstate Alliance Property Navigator" item points at this now-dead host). `webgis.net/arcgis/rest/services` resolves but holds only NC/VA/Utilities/Secure folders — no SC. `smpesri.scdot.org/arcgis/rest/services` resolves and was fully recursed (GISMapping = Bridges + SC_Contours only; Hosted = 298 services, zero parcel/tax/address layers; the old SC_Parcels layer is gone from the public tree). `gis.state.sc.us/arcgis/rest/services` (SC Revenue & Fiscal Affairs) resolves — folders `Boundaries_Districts, Census, District_Info, Geocode, Geodetic, NG911, Transportation_Carrier_Network` — all boundary/geocode, **no parcels, no tax**. The one real hit came from Sweep 2 and is listed below (`SC_GaffneyCity_01`).

**SWEEP 2 — ArcGIS Online item enumeration.** No Cherokee County SC AGOL org exists: `cherokeecountysc.maps.arcgis.com` and `cherokeecosc.maps.arcgis.com` both return `portals/self` with `id: null` (generic AGOL, not an org). `owner:CherokeeCountySC` → 0 items. `GDITAdmin / "Parcels - SC - Cherokee County"` (135664e4fd214f2dbc7540bc4e486931) → **403 "Subscription is canceled"** = DEAD. I pulled `/data?f=json` for all six RFA "County Data Submission Survey" web maps (Parcels, Address Points, Tax Districts, Zoning, Roads, Municipal) — every one resolves to the same survey123 layer, **no definitionExpression anywhere**, no per-county service URLs. Querying that layer for Cherokee returned only administrative metadata (FIPS 45021, COG = Appalachian COG, contact `mkelley@scacog.org`, `parcels_required: Yes`, `Date_Certified: null`). The productive find was `canoewood / SC_GaffneyCity_01`, which carries a **Parcels - Gaffney Area** layer and a **City Address Points** layer keyed on the Cherokee TMS.

**SWEEP 3 — site structure.** `robots.txt` (WordPress boilerplate, `Crawl-delay: 10`) and `sitemap.xml` both live at the real domain **`cherokeecountysc.gov`** (`cherokeecountysc.com` 301s there). Sitemap = 160 URLs, one `<urlset>`, no index. Distress-relevant paths: `/delinquent-tax/`, `/delinquent-tax/tax-sale-bidders/`, `/delinquent-tax/tax-collection-and-tax-sale-procedures/`, `/delinquent-tax/unpaid-2020-delinquent-tax-list/`, `/register-of-deeds/`, `/probate-court/estates/`, `/clerk-of-courts-office/`, `/assessor/search-our-records/`, `/gis-mapping/gis-parcel-map/`, `/building-safety/unpermitted-work-report/`, `/assessor/residential-exemption-fraud-report/`, `/finance-purchasing/bid-packages-results/`, `/sheriffs-office-detention-center/detention-center/`, `/capital-and-planning-projects/zoning/`, `/addressing/`. The sitemap is a **subset** — it covers 160 of the 2,411 WP objects the REST API exposes.

**SWEEP 4 — search-engine sweep.** New hosts surfaced: `gaffneyledger.com` (the paper of record for Cherokee legal notices), `sclandrecords.com/sclr/` (ROD), `cherokeecountysctax.com` (tax portal), `xpressformsbuilder.com` (bidder registration), plus commercial-only parcel resellers (Regrid / USLandGrid / Dynamo Spatial / Mapping Solutions — all PAID, no free SC parcel download exists). No Master-in-Equity page exists for Cherokee — SC foreclosure rosters route through the sccourts Public Index. `site:cherokeecountysc.gov` surfaced two orphan PDFs that no page links (`Copy-of-GAFFNEY-LEDGER-FIRST-FILE-11-14-23.pdf`, `Bidder-List-Update-12-3-21-PDF.pdf`), which is what pointed me at the WP media index. No condemned/nuisance/demolition list is published anywhere for the county or for Gaffney.

### Top 3 net-new

1. **`wp-json/wp/v2/media` as the tax-sale discovery lane.** The county's actual parcel ledgers are uploaded but never anchored on `/delinquent-tax/`, so the existing PDF-anchor scraper structurally cannot reach them. `?search=tax%20sale` returns the whole 2021–2025 run, and the one I parsed (`Tax-Sale-List-2024-1.pdf`) is **529 unique TMS with owner name and situs**. The 2025 sale ran 2025-12-08 with the list due to post ~three weeks prior, so polling this endpoint is also the trigger for the next cycle.

2. **`SC_GaffneyCity_01` FeatureServer layers 14 + 16.** The only free ArcGIS parcel/address data covering any part of Cherokee County SC. Layer 16 carries both TMS formats the engine already juggles (`ParcelNum` dashed, `OldPin` 13-digit) plus a prebuilt `QpublicURL`; layer 14 joins **13-digit `MAPNUMBER` → `DLVRY_ADD` + lat/lng + structure type** across 7,116 Cherokee points. That directly attacks the address-less-lead problem for court-feed parcels, which arrive 13-digit numeric — the exact format `_norm_cherokee_pid` was written to re-dash. `StructureT ∈ {No Structure, Power Only}` is a free vacancy proxy on top.

3. **`/delinquent-tax/unpaid-2020-delinquent-tax-list/` HTML table.** The only Cherokee source that publishes a **dollar amount per parcel** (`OPENING BID`) alongside owner and situs, and it is plain HTML rather than a scanned PDF. Stale (2020, 114 rows) and no other year was ever published this way, but it is a clean structured-format reference and a live URL the engine currently ignores.

**Compliance note:** every URL above was fetched. Nothing here required defeating a CAPTCHA or WAF — `publicindex.sccourts.org` (406) and the ROD login at `sclandrecords.com` are classified as walls and left alone; the qPublic 403s are a TLS-fingerprint rejection the engine already handles legitimately with `curl_cffi`. No repo files were written, no git was run, and the engine was not started.
