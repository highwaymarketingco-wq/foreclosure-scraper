### Top 3 net-new

1. **`https://arcgisserver.lincolncountync.gov/ftp/{parceldata,parcels,sales,improvements,address,zoning}.zip`** — six open bulk dumps totalling ~67 MB, **refreshed 2026-08-01** (two days before this run), no auth, no rate limit, directory index 403 but every file 200. 2. **`Server_Tables/MapServer/10` (TXPID)** — the taxpayer contact spine the engine has never touched: 291,480 rows, **99,347 with a reconstructable phone** (`TCACDE`+`TCPEXT`+`TCPHON`, e.g. 704-735-0257) and **30,152 with an email**, plus mailing address. Given the known `owner_mailing` breakage, this is a direct contact-layer fix for one county — and it ships with an exposure caveat: the layer also publishes `TCSSN1`/`TCSSN2` columns, which I deliberately did not query and which you should treat as off-limits.
3. **`https://gis.lincolncountync.gov/server/rest/services`** — an entire **second ArcGIS Server** the engine has no reference to, whose `OpenGov/OpenGov/MapServer/58` (`MAT_OpenGov_View_FC`) serves **83,910 pre-geocoded rows** with owner name, mailing address, `VACANT`, `PROPERTYTYPE`, deed book/page **and lat/lon in the same row** — bypassing the name→parcel→geocode chain entirely. It exists only because a JS config file named it; no hostname-guessing pattern would have reached it.
