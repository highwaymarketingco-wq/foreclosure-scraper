### Top 3 net-new

1. **`Accela/MapServer/6` — countywide owner file with 73,965 phone numbers.** This is the single highest-value find in the sweep: a free, unauthenticated, county-published `ParcelNumber → OwnerFullName + Phone + Phone2 + full mailing address` join table covering all 135,079 parcels. It turns every other Buncombe distress signal (delinquent bill, red placard, landslide, HMGP application) into a directly-callable lead, and it collapses the name→property→contact backbone for the county without skip-tracing.

2. **`Unpaid Property Bills from <YYYY>` FeatureServers, 2009–2026.** Sixteen years of per-bill delinquency as queryable JSON with `total_due`, `interest_due`, `mortgage_co`, `loan_num`, deed reference, and owner mailing address. The engine currently OCRs one annual PDF; this replaces that with structured, multi-year data (2025 = 7,922 residual, 2024 = 6,255, 2019 = 890 still unpaid) and directly closes the known "82%-Buncombe gap" in NC delinquent-tax coverage — including aged arrears that never appear in the current-year statutory advertisement.

3. **`HeleneCombinedDamageAssessmentResults_Clipped` + `Accela/MapServer/7`.** 1,542 **red-tagged** and 5,728 yellow-tagged structures with 734 confirmed `substantial_damage_determination = yes`, joined to `pinnum`, plus 10,723 parcels flagged `NATURAL DISASTER - DESTROYED`. The existing Helene enricher reads a right-of-entry/debris service, not the placard file — this is the actual condemnation-grade signal, and red-tag + unpaid-2025 + out-of-state mailing is a three-way intersection that runs entirely inside these two hosts.
