## Top 3 net-new

1. **`Assessor_Extract.csv`** — `https://www.arcgis.com/sharing/rest/content/items/1f190ebd48c1402a918c3bc315431a1b/data`. A public, weekly-refreshed, 123 MB single-file dump of the entire Spartanburg assessor roll with **OwnerName + TaxpayerName + mailing StreetAddress/City/State/Zip + PropertyLocation + PreviousOwnerName + sale + value + ConditionFactor/CDUC**. This directly attacks the two known engine ceilings in memory (the `owner_mailing` mail spine and the ~25-30% name→parcel resolution rate) without paginating 181,369 ArcGIS features. It is not linked from any county web page and has no `url` field on its AGOL item, which is why category-driven searches never found it.

2. **The county's disaster-damage triad on `services6/YJV3IFNXuNHJDIvn`** — `Property_Damage_Assessments/FeatureServer/**25**` (1,531; Parcel_ID + Occupant_Name + Building_Damage "Destroyed/Major" + Estimated_Loss), `Palmetto_Property_Damage/FeatureServer/**2**` (696; + Occupancy_status + Insurance_types), and `Private_Property_Cleanup_Locations/FeatureServer/**13**` (2,359 rows, **2,349 carrying an owner phone number**). This is a distress *source*, not an enrichment: destroyed/major-damage single-family with a named occupant and a live phone. Note the layer IDs — a scraper that assumes `/0` gets nothing.

3. **City of Spartanburg Master Condemnation List PDF** — `https://www.cityofspartanburg.org/DocumentCenter/View/1901/City-of-Spartanburg-Master-Condemnation-List-`. 92 condemned properties, refreshed 2026-07-23, each row already carrying property address + tax map + owner (with LLC registered agent named) + **owner mailing address** + condemnation date. Fully resolved leads requiring no parcel-resolver pass. Pairs with the `commercial_properties` survey (362 zoning violations, 806 dumping) for a complete city blight layer, and works around the county's FOIA-gated condemned list.
